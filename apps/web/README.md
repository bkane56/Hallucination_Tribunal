# Hallucination Tribunal — Web UI

Next.js 15 frontend for The Hallucination Tribunal.

See the [root README](../../README.md) for setup, environment variables, and deployment.

```bash
yarn install
yarn dev      # http://localhost:3000
yarn test
yarn test:e2e
```

Set `NEXT_PUBLIC_BACKEND_URL=http://localhost:8000` (or your Render API URL in production).
