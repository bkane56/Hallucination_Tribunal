# Software Engineering Standards

## Testing Requirements

All production releases require minimum 90% unit test coverage for business logic.

Integration tests are required for API endpoints and data pipelines.

## Code Review

All code changes require approval from at least one senior engineer before merge to main.

## Deployment

Production deployments require passing CI checks, security scan, and change management ticket.

## Logging Standards

Applications must log structured JSON with correlation IDs. Secrets must never appear in logs.

## AI-Generated Code

Code generated by AI tools requires the same review and testing standards as human-written code.
